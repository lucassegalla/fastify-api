# Fastify API Basics

Projeto de estudos de backend com Node.js e Fastify, implementando uma API REST para aprender os principais conceitos do framework

### Tecnologias:

- Node.js
- Fastify
- JavaScript

### Estrutura:

server.js
routes/
controllers/
services/
data/

### Rotas Implementadas:

- GET /usuarios

### Como executar:

npm install
node server

Servidor disponível em: http://localhost:3000
